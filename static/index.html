Kiểm tra đầu vào

Cấu hình model / GPU Mac

Chọn Mac Metal/MPS để chạy hai model trực tiếp trên Mac. Mạng chạy bằng GPU Apple; tạo pillar và lọc box chạy trên CPU. Dữ liệu được xử lý trên máy.

Giữ 1 để dùng intensity gốc. Chỉ thay đổi khi biết dữ liệu đã được chuẩn hóa khác nuScenes. Đơn vị tọa độ: mét, Z hướng lên.

Đang kiểm tra model

Mac: checkpoint được giữ trong mac_models/checkpoints. Máy mới chạy ./setup_mac.sh một lần, sau đó ./run.sh. Mỗi frame chạy riêng; box là đề xuất cần kiểm tra.

Tải notebook Colab GPU · Tải worker cho Linux NVIDIA

Colab: chọn runtime GPU, chạy notebook, dán URL và token ở ô trên. Notebook tự tải checkpoint của cả hai model.
